# Material Design 3 — Motion & Background

Дополнение к `material_design_3_dark_theme_guide.md`: как в проекте устроены
анимации, почему фон именно такой и что можно добавить дальше.
Реализация: `app/m3-motion.css` (последний импорт в `app/layout.tsx`) +
`components/m3-ripple.tsx`. Существующие CSS-файлы (opus/diamond) не трогаем —
motion-слой только дополняет их.

## Принципы

1. **Движение смысловое, а не декоративное.** Продукт для людей с СДВГ:
   анимация показывает, откуда элемент пришёл и что делать дальше
   (например, «дышащее» кольцо текущей задачи), а не развлекает сама по себе.
2. **Кривые M3.** Вход на экран — `emphasized-decelerate`
   `cubic-bezier(0.05, 0.7, 0.1, 1)`, общие переходы — `emphasized`
   `cubic-bezier(0.2, 0, 0, 1)` (та же кривая, что предписана гайдом темы).
3. **Шкала длительностей M3.** Short 50–200 мс (состояния), medium 250–400 мс
   (экраны, меню), long 450–600 мс (карточки). Дольше ~1 c — только награды
   (орб, шкала XP) и фон.
4. **Только GPU-свойства:** `transform`, `translate`, `scale`, `opacity`.
   Отдельные свойства `translate`/`scale` компонуются с `transform` и не
   ломают инлайн-позиционирование станций метро и узлов ReactFlow.
5. **`prefers-reduced-motion` отключает всё**, включая фон и бесконечные
   циклы (флейм, шиммер, дыхание текущей задачи).

## Токены

Заведены в `:root` (`app/m3-motion.css`, секция 0):

| Токен | Значение | Где использовать |
| --- | --- | --- |
| `--m3-ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | hover/pressed, перемещение внутри экрана |
| `--m3-ease-emphasized-decelerate` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | элементы, входящие на экран |
| `--m3-ease-emphasized-accelerate` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | элементы, уходящие с экрана |
| `--m3-dur-short-1…4` | 50–200 мс | state layers, иконки |
| `--m3-dur-medium-1…4` | 250–400 мс | экраны, меню, панели |
| `--m3-dur-long-1…4` | 450–600 мс | крупные карточки, контейнеры |
| `--m3-state-hover / --m3-state-pressed` | 8% / 12% | прозрачность state layer по спецификации M3 |

## Что анимировано

- **Переходы экранов** — Каталог / Детали / Фокус дня / Профиль появляются
  fade + подъём на 12px (`m3-screen-in`), без JS: экраны монтируются при
  смене `view`/`selected`.
- **Каскады (stagger)** — карточки каталога (`--m3-stagger` из `page.tsx`,
  шаг 45 мс), станции метро вдоль линии (шаг 70 мс), секции профиля,
  плашки статистики, огоньки дней стрика.
- **Ripple** — фирменная «чернильная» волна Material на кнопках, пилюлях
  навигации, вкладках сортировки, чекбоксах задач (`components/m3-ripple.tsx`,
  один делегированный слушатель).
- **Hover/pressed** — карточки поднимаются тонально (поверхность + лавандовый
  ореол, а не тяжёлая тень — по гайду тёмной темы), превью внутри карточки
  мягко масштабируется; иконки навигации растут; кнопки «назад» сдвигаются
  влево; pressed-состояние — `scale: 0.95–0.99` везде.
- **Меню и панели** — меню задачи раскрывается от угла (M3 menu),
  форма создания роудмапа — container-reveal сверху.
- **Фокус дня** — текущая задача «дышит» кольцом акцента; существующие
  check-pop, рост стрелок и орб сохранены как есть.
- **Профиль** — шкала уровня вырастает из нуля с точкой-стопом M3 на конце,
  общий XP считается вверх (count-up), аватар и бейдж появляются поп-ином;
  флейм стрика уже был анимирован — не дублируем.

## Фон: решение и обоснование

**Добавлен ambient-слой «северное сияние»**: три сильно размытых пятна
фирменного лавандового `#D0BCFF` (7–15% цвета акцента), дрейф 44–72 секунды,
`filter: blur(90px)`, поверх — прозрачный `.opus-shell`. Сияние видно только
в негативном пространстве вокруг карточек; сайдбар и карточки остаются
непрозрачными поверхностями `#16181B/#1D2024`.

Почему так, а не «живой» фон с частицами/звёздами/сеткой:

- **Продукт про концентрацию.** Периферийное движение постоянно дёргает
  внимание — для аудитории с СДВГ это прямой вред. Дрейф на грани восприятия
  даёт глубину графита, не отвлекая от текущего шага.
- **M3 dark — это тональность, а не эффекты.** Гайд темы строит глубину
  ступенями поверхностей и запрещает неон/холодный синий. Лавандовый градиент
  из того же акцента — единственный фон, который не спорит с системой.
- **Производительность.** Три статичных градиента + transform — почти
  бесплатно; canvas-частицы — постоянный расход батареи и кадров.

Настройки: интенсивность — проценты в `color-mix(...)` у `.m3-ambient-blob-*`,
скорость — длительности `m3-ambient-drift-*`. Полностью выключить — удалить
блок `.m3-ambient` из `app/layout.tsx`.

## Идеи на будущее (ближе к M3, по возрастанию усилий)

1. **Roboto Flex / шрифт с кириллицей.** Сейчас Geist подключён только с
   `subsets: ["latin"]`, русский текст падает на системный шрифт. M3-путь —
   Roboto Flex (есть кириллица) или Geist с `cyrillic` subset + шкала
   M3 Type Scale (Display/Headline/Title/Body/Label).
2. **FAB «Создать роудмап»** вместо кнопки в топбаре на мобильных и
   **Navigation Bar** (нижняя навигация M3) вместо сайдбара ≤1024px.
3. **Snackbar** для «День завершён / +100 XP» вместо статичных плашек —
   с действием «Следующий день».
4. **Segmented buttons** для сортировки каталога (сейчас пилюли близки,
   осталось выровнять высоты/состояния по спецификации) и **Filter chips**
   по категориям.
5. **Shared-element переходы** через View Transitions API: карточка каталога
   «раскрывается» в детали роудмапа (container transform — коронный паттерн M3).
6. **Dynamic color**: палитра карточки уже хранит свой accent; можно тонировать
   детали роудмапа и метро его цветом (tonal palettes HCT), а не только превью.
7. **Skeleton с шиммером** на время генерации скелета/дня вместо текстового
   «Генерация…» — карточки-призраки в сетке каталога и в метро.
8. **Progress indicators M3 повсеместно**: линейный индетерминированный
   индикатор под топбаром при LLM-запросах (сейчас только текст на кнопке).
9. **Level-up момент**: полноэкранный, но короткий (≤1 c) акцент при
   повышении уровня — кольцо + цифра, в дополнение к существующим частицам XP.
